## Projects

### 1. [KnotGridRand](https://github.com/Ahmedg2v/knotgridrand)
**Python · Computational Physics · Monte Carlo Methods · Scientific Computing**

A Python toolkit for representing, randomising and analysing 3D knots on a cubic lattice.

The project implements stochastic knot randomisation using:
- **BFACF algorithm:** Local Monte Carlo moves involving lattice expansion, contraction and corner modification.
- **Slide moves:** Non-local moves that introduce large-scale configurational changes.
- **Energy-based acceptance:** A configurable energy function used to control the probability of accepting proposed moves.

The toolkit is designed to support computational experiments involving randomised knot configurations.

**Key areas:** Computational geometry, lattice models, stochastic simulations, algorithm design and scientific Python.

### 2. [NN_numpy](https://github.com/Ahmedg2v/NN_numpy)
**Python · NumPy · Machine Learning · Neural Networks**

A modular feedforward neural network implementation built entirely from scratch using Python and NumPy, without relying on deep learning frameworks.

The implementation explores the fundamental components of neural networks, including:
- Dense layers and configurable network architectures.
- Forward and backward propagation.
- Activation functions, including ReLU, Tanh, Softmax and Leaky ReLU.
- Optimisation algorithms, including SGD, SGD with momentum and Adam.
- Mini-batch training and model evaluation.

The repository also includes examples demonstrating the training and evaluation of neural networks on the MNIST handwritten digit dataset.

**Key areas:** Numerical computing, linear algebra, optimisation, machine learning and object-oriented programming.

### 3. [KnotsNN_HPC](https://github.com/Ahmedg2v/KnotsNN_HPC)
**Python · High-Performance Computing · Machine Learning · SLURM**

A collection of scripts developed for my MSci research project, *Machine Learning Based Classification of Knots*.

The project combines stochastic knot randomisation with neural network classification, using computational resources to generate training datasets and investigate machine learning approaches to knot classification.

It includes:
- Automated generation of large datasets of randomised knot configurations.
- HPC workflows for distributing computational tasks.
- SLURM job scripts, including job arrays.
- Neural network training and classification experiments.

The project demonstrates the application of Python-based scientific computing and machine learning within an HPC environment.

**Key areas:** High-performance computing, parallel workflows, data generation, neural networks and computational research.

### 4. [Forest Fire Model](https://github.com/Ahmedg2v/forest_fire)
**Python · Jupyter Notebook · Numerical Simulation · Statistical Physics**

A numerical simulation of the Drossel–Schwabl forest-fire model (DS-FFM), investigating its critical behaviour in two dimensions.

The model is implemented on a finite 2D lattice with periodic boundary conditions, exploring the dynamics of tree growth, lightning strikes and fire propagation.

The project provides an opportunity to investigate emergent behaviour and critical phenomena through computational simulation.

**Key areas:** Statistical physics, cellular automata, numerical modelling and computational experiments.
